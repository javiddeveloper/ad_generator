## Overview

A reusable form component for collecting basic business information. Includes three required fields with inline validation feedback.

---

## Fields

| Field | Type | Required | Validation |
|---|---|---|---|
| Business Name | text | Yes | Non-empty, min 2 chars |
| Address | text | Yes | Non-empty |
| Phone Number | tel | Yes | Valid phone format (see below) |

### Phone Format Rules

Accepted formats:
- `+98 912 345 6789`
- `09123456789`
- `+1 (555) 000-0000`

Regex pattern:
```
/^[+]?[(]?[0-9]{1,4}[)]?[-\s./0-9]{7,14}$/
```

## Validation Behavior

- Validation triggers **on blur** for each field (not on every keystroke).
- On submit, all fields are validated simultaneously.
- Error messages appear below the relevant input.

### Error Messages

| Field | Condition | Message |
|---|---|---|
| Business Name | Empty | `Business name is required` |
| Business Name | < 2 chars | `Business name must be at least 2 characters` |
| Address | Empty | `Address is required` |
| Phone | Empty | `Phone number is required` |
| Phone | Invalid format | `Enter a valid phone number` |

---

## UI States

| State | Description |
|---|---|
| Default | Empty fields, no error shown |
| Touched + Invalid | Red border + error message below field |
| Touched + Valid | Default border, no error |
| Submitting | Submit button disabled, optional spinner |
| Success | `onSubmit` callback fires with validated values |

## Example: Form State (React)

```tsx
const [values, setValues] = useState({ businessName: "", address: "", phone: "" });
const [errors, setErrors] = useState<Partial<typeof values>>({});

function validate(values: typeof values) {
  const errors: Partial<typeof values> = {};
  if (!values.businessName.trim()) errors.businessName = "Business name is required";
  else if (values.businessName.trim().length < 2) errors.businessName = "Must be at least 2 characters";
  if (!values.address.trim()) errors.address = "Address is required";
  if (!values.phone.trim()) errors.phone = "Phone number is required";
  else if (!/^[+]?[(]?[0-9]{1,4}[)]?[-\s./0-9]{7,14}$/.test(values.phone)) {
    errors.phone = "Enter a valid phone number";
  }
  return errors;
}

function handleSubmit(e: React.FormEvent) {
  e.preventDefault();
  const errs = validate(values);
  if (Object.keys(errs).length > 0) { setErrors(errs); return; }
  props.onSubmit(values);
}
```
